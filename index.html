School Assistant

A personal study organiser by Brandon Onishenko. Last updated: 2026-10-15.

School Assistant is a small program that its developer runs on the developer's own computer, for the developer's own use. It is not a public service and has no other users. It helps one student keep track of coursework.

What it does

  • Collects assignment and exam deadlines from the student's course calendar feed and course outlines (PDF files the student supplies).
  • Reads the student's school email in read-only mode, to find deadlines, schedule changes and cancellations, and to show a short summary of recent messages.
  • Sends the student reminders, a daily brief and answers to questions through a private chat message.
  • Shows the student's courses, deadlines and degree progress on a web page that only the student's own computer can open.

How it uses Google data

The app asks for one Google permission: https://www.googleapis.com/auth/gmail.readonly (view email messages). It uses this only to read the developer's own school mailbox so that the program can organise the developer's own deadlines. It cannot send, delete, or change any email.

Everything the app reads is processed by a language model that runs on the same computer. Email content is not sent to a cloud AI service. See the privacy policy for details.

School Assistant's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
