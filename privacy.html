Privacy policy

School Assistant. Last updated: 2026-10-15.

School Assistant is a personal program run by Brandon Onishenko ("the developer") on the developer's own computer. The only person whose data it handles is the developer. This policy explains what it does with Google user data.

Data accessed

With the developer's permission, the app uses the Gmail read-only scope (gmail.readonly) to read messages in the developer's school mailbox: sender, subject, date and message text. It does not request any other Google permission and cannot send, modify or delete email.

How the data is used

  • To find deadlines, date or room changes and cancellations in messages, and propose them as tasks. The developer reviews proposed tasks before they are saved.
  • To produce a one-line summary of each message and to judge whether it concerns the developer's courses.
  • To answer the developer's own questions (for example "any new emails about my exam?") in a private chat.

The data is not used for advertising, is not sold, and is not used to train any model.

Where the data is processed and stored

  • On the developer's computer. Messages are stored in a local database. The text of a message is deleted 30 days after it has been read; short summaries and the deadlines the developer accepted are kept until the developer deletes them.
  • Language model. Reading and summarising is done by a language model running locally on the same computer. Message text is not sent to any external AI service.
  • Login credentials. The Google login token is kept in the computer's secure credential store (the macOS Keychain), not in files.
  • Backups. The developer may keep an encrypted backup of the local database on a drive the developer chooses.

Sharing

Google user data is not shared with, sold to, or disclosed to any third party, with one exception that the developer controls: the app can send reminders and chat answers to the developer's own private Discord account. Those messages can contain details drawn from an email (for example the name and date of a deadline). Beyond that, no one else receives the data and no one else has access to it, except where required by law.

Limited Use

School Assistant's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements. No humans read the data except the developer, who owns the mailbox.

Retention and deletion

The developer can stop access at any time at myaccount.google.com/permissions by removing School Assistant, and can delete all stored data by deleting the program's local database. Message text is removed automatically after 30 days.

Security

The program's web page can only be opened from the computer it runs on, credentials are stored in the system credential store, and Google data stays on that computer, except for the reminders described above.
